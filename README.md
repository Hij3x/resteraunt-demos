# Restaurant Website Demo Collection

Five fictional restaurant demo websites plus one directory homepage.

## GitHub Pages setup
1. Create a public GitHub repository.
2. Upload **the contents of this folder** to the repository root (not the ZIP).
3. Go to **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, then save.
4. Open the GitHub Pages URL shown in Settings. Each demo opens via a relative link and works on project Pages URLs.

## Files
- `index.html` — demo collection homepage
- `bella-notte/index.html`, `smash-district/index.html`, `bloom-cafe/index.html`, `zaytoun/index.html`, `koi-house/index.html` — independent restaurant pages
- `style.css`, `app.js` — shared assets

## Notes
- Photos load from Unsplash and require internet.
- Carts, checkout, and reservations work in the browser only and are explicitly labeled as demonstrations. No payment, backend, or booking system is connected.
- Sample prices are CAD, before taxes.
- Restaurant names, addresses and details are fictional.
